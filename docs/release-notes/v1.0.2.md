# Jenkins AI Copilot 1.0.2

An agentic CI/CD assistant that installs as a single Jenkins plugin.

## Highlights

- **Single HPI.** No external backend, database, Compose stack, or Jenkins-agent Node.js dependency.
- **Multiple provider accounts.** OpenAI, Claude, opencode go, and any OpenAI-compatible endpoint, each with an encrypted key and default model.
- **Pipeline-grouped sessions.** Search, rename, delete, and collapse sessions; multibranch branches group under the parent project.
- **Broken-build triage.** A failing or unstable latest build pulses the FAB/sidebar and offers **Quickly analyse**.
- **Readable agent activity.** Reasoning appears in a collapsible **Analysis** panel, tool narration stays plain text while streaming, and the final answer renders as Markdown.
- **Copy response.** Every assistant message has a Copy button that copies the raw Markdown.
- **Custom pickers.** Provider, model, and thinking menus are measured and anchored to their trigger, with searchable provider-grouped models.
- **Manage Jenkins, not just diagnose it.** Typed tools cover views, folders, queue items, permanent agents, credentials, users, the Global Matrix permission matrix, plugins, and controller settings.
- **Approval-gated actions.** Privileged Jenkins and GitHub operations require explicit human approval.

## Security

- Provider keys and GitHub tokens are Jenkins `Secret` values and never reach the browser.
- Sessions and attachments are scoped to their owning Jenkins user.
- Account management is admin-only; non-admins see only the masked account list.

## Upgrade notes

- Legacy keys on **Manage Jenkins → System → Jenkins AI Copilot** are imported once into the encrypted account store.
- Session data remains under `$JENKINS_HOME/jenkins-ai-copilot`.
- Build with JDK 21.

## Verification

- 42 plugin tests pass (1 skipped by the test harness).
- Frontend typecheck and bundle build pass.
- HPI packaging succeeds with Maven.

## Install

1. Build `jenkins-plugin/target/jenkins-ai-copilot.hpi`.
2. Open **Manage Jenkins → Plugins → Advanced settings**.
3. Upload the HPI under **Deploy plugin**.
4. Open the drawer and add a provider under **Settings → Providers**.
