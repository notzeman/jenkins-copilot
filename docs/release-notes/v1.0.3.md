# Jenkins AI Copilot 1.0.3

A UI-focused release that makes the Copilot drawer feel native to Jenkins.

## Highlights

- **Jenkins-native icon set.** Replaced mixed icon styles with Jenkins symbols and a dedicated Copilot mark.
- **Refined drawer and session manager.** Return to the session manager from chat with a back button, close the
  sidebar from the session list, and reach Settings without leaving the session manager.
- **Clearer assistant responses.** Copy response now sits at the bottom-right of each completed response,
  reasoning has its own collapsible analysis panel, and tool cards show friendlier metadata.
- **Approval workflow polish.** Always-visible approval actions above the composer and a clearer
  approval/analysis layout.
- **Refreshed documentation.** New README artwork, screenshots, and release assets.

## Management capabilities

- Views and dashboards, folders, jobs, queue items, permanent agents, credentials, users, the Global Matrix
  permission matrix, plugins, and controller settings.
- Typed, validated, approval-gated tools. Admins can explicitly bypass approvals from the shield control.

## Security

- Provider keys and GitHub tokens remain encrypted Jenkins `Secret` values.
- Sessions and attachments are scoped to their owner.
- Approval mode changes are audited.

## Verification

- 42 plugin tests pass (1 skipped by the test harness).
- Frontend TypeScript typecheck and production bundle build pass.
- HPI packages with JDK 21.

## Install

1. Download `jenkins-ai-copilot.hpi` from this release.
2. Verify it against `jenkins-ai-copilot.hpi.sha256`.
3. In Jenkins, open **Manage Jenkins → Plugins → Advanced settings**.
4. Upload the HPI under **Deploy plugin**.
5. Open the Copilot drawer and configure a provider under **Settings → Providers**.
