# Jenkins AI Copilot 1.0.4

Reusable, admin-managed skills that keep repeated Jenkins work cheap.

## Highlights

- **Skills tab.** Create, edit, enable, disable, and delete reusable Markdown procedures in Settings → Skills.
- **Draft from pipelines.** Pick a folder scope and let Copilot scan pipeline structure, distil the repeated
  pattern, and propose a skill for approval.
- **On-demand context.** The assistant sees only a compact skill catalogue; the full body is fetched with
  `get_skill` only when a skill matches. This avoids re-reading every Jenkinsfile.
- **Generic, not pipeline-only.** Skills can cover pipeline creation, failure triage, release/rollback, security,
  agent provisioning, views, plugin upgrades, onboarding, and custom team procedures.
- **Pipeline pattern scanner.** `scan_pipelines` returns compact stages, agents, environment keys, credential IDs,
  and feature flags without dumping full Jenkinsfiles.
- **Approval-gated changes.** `create_skill`, `update_skill`, and `delete_skill` are risk 3 and always pause for
  approval; enable/disable is risk 2.

## Security

- Skills are global and admin-managed; only administrators can create or modify them.
- Enabled skills are offered to every assistant user; disabled skills stay out of the system prompt.
- Skill content is operator-approved guidance and cannot override system policy, approval rules, or secret
  redaction.
- Skill writes are audited. Do not put secrets in a skill; use Jenkins credential IDs.

## Verification

- 48 plugin tests pass (1 skipped by the test harness).
- Frontend typecheck and production bundle build pass.
- HPI packages with JDK 21.

## Install

1. Download `jenkins-ai-copilot.hpi` from this release.
2. Verify it against `jenkins-ai-copilot.hpi.sha256`.
3. In Jenkins, open **Manage Jenkins → Plugins → Advanced settings**.
4. Upload the HPI under **Deploy plugin**.
5. Configure a provider under **Settings → Providers**, then open **Settings → Skills**.
